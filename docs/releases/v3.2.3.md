## 更新内容

v3.2.2 曾临时退回到 v3.2.0。这个版本重新带上 v3.2.1 的全部改进，修好了点微信消息会弹出登录框的问题，另外新增一项功能。

- **修复：点微信消息会弹出微信登录框**：v3.2.1 里，微信已经登录、但窗口不在前台时，点小岛上的微信消息会弹出「进入微信」登录框，跳不进微信。现在会直接切到已打开的微信窗口；窗口收在托盘里时，交给微信自己的唤起入口处理，不会再重新启动微信。
- **待办图标上的更新红点**：有新版本等着安装时，小岛顶部的待办图标上会一直显示小红点，不用点进待办页才看到。
- **点开一个人只清这个人的消息**：从小岛点开某个联系人或会话后，只清掉这个人的消息，其他人的消息留在岛上。比如小明发了 3 条、小红发了 2 条，点开小明后，小红的 2 条还在。邮箱仍然只标记你打开的那一封。
- **「这些时候不贴边」更可靠**：以前这些开关只挡住下一次自动贴边，小岛已经贴边后再开始放歌、Agent 开始运行或待办开始计时，它还是一条线。现在条件一成立就会把自动贴边的小岛叫出来。待办计时结束后，也会重新按设定贴边。
- **消息到来时小岛能正常弹出**：以前判断「有全屏应用」只看 Windows 的一个猜测值，部分电脑上会一直误判，游戏模式就把消息弹出吞掉了。现在要前台窗口真的铺满屏幕才算全屏。
- **打开微信不再报「找不到应用程序」**：点微信消息时，会直接切到已经打开的微信窗口，或者找到微信程序把它打开，不再依赖 `weixin://` 链接，也不会再弹出系统的错误框。打不开时小岛上会提示原因。
- **Alt+Tab 不再被打断**：透明的小岛不再出现在 Alt+Tab 列表里，聚焦窗口时也不再模拟按 Alt 键，不会打断你正在进行的窗口切换。快捷键也不能再设成 Alt+Tab、Win+L 这类系统组合。
- **DSH 余额和会话**：用 Beta、NEXT 或自定义数据目录的 DSH 也能查到余额；DSH 升级后会话不会再整个消失；查询带超时和重试，查不到时会显示原因，比如未找到凭据、凭据失效或查询超时。
- **WorkBuddy 重启后保持登录**：登录信息加密保存在 Windows 凭据管理器里，重新打开小岛后会自动恢复，不用每次重新登录。点「断开」时一并清除。
- **玻璃质感下的面板更协调**：液态玻璃和磨砂玻璃下，翻译页、文件中转页的面板和岛内设置页的左栏，不再是一块深色（或白色）的盒子，改成和玻璃同色调的淡底和细描边。
- **设置页重新整理**：「通用」和「外观」两页按用途重新分组。「通用」依次是启动与语言、展开与收起、贴边隐藏、这些时候不贴边和位置；「外观」依次是主题、颜色、字体与大小、岛上的排列、展示优先级和外形。选项一个没少，原来的设置都保留。

## What's new

v3.2.2 temporarily went back to v3.2.0. This version brings back everything from v3.2.1, fixes WeChat messages opening the sign-in dialog, and adds one new feature.

- **Fixed: clicking a WeChat message opened the WeChat sign-in dialog**: in v3.2.1, with WeChat signed in but not in front, clicking a WeChat message on the island showed the sign-in dialog instead of opening WeChat. The island now switches to the open WeChat window, and when WeChat is in the tray it uses WeChat's own way of bringing it back, without starting WeChat again.
- **Update dot on the todo button**: while a new version waits to be installed, the todo button at the top of the island keeps a red dot, so you no longer have to open Todos to see it.
- **Opening one person clears only their messages**: opening a contact or conversation from the island clears that person's messages and leaves everyone else's. If Ming sent 3 and Hong sent 2, opening Ming keeps Hong's 2. Mail still marks only the email you opened.
- **"Stay visible while" is more reliable**: these switches used to block only the next automatic tuck, so if the island was already tucked when music, an agent or a to-do timer started, it stayed a line. Now the island comes back as soon as the condition starts, and tucks again as set once a to-do timer ends.
- **New messages bring the island out again**: full-screen detection used to rely on a single Windows hint that stays wrong on some PCs, so game mode swallowed message pop-ups. A window now has to really fill the screen to count as full screen.
- **Opening WeChat no longer says "application not found"**: clicking a WeChat message switches to the open WeChat window or starts WeChat from its program file instead of relying on the `weixin://` link, and never shows the system error box. If it cannot open WeChat, the island says why.
- **Alt+Tab is no longer interrupted**: the transparent island no longer appears in the Alt+Tab list, and focusing a window no longer fakes an Alt key press that could break a window switch in progress. Shortcuts can no longer be set to system combinations such as Alt+Tab or Win+L.
- **DSH balance and sessions**: the balance now works with DSH Beta, NEXT and custom data folders; sessions no longer disappear after a DSH update; queries time out and retry, and when the balance cannot be read the island shows why, such as credentials not found, expired credentials or a timeout.
- **WorkBuddy stays signed in after a restart**: the sign-in is stored encrypted in Windows Credential Manager and restored when the island reopens, so you no longer sign in every time. Disconnect clears it.
- **Panels fit the glass materials**: with Liquid or Frosted glass, the Translate and File shelf panels and the island's settings sidebar are no longer a dark (or white) box; they use a faint tint of the glass with a thin edge.
- **Settings reorganized**: General and Appearance are regrouped by purpose. General: startup and language, expand and collapse, tucking, stay visible while, position. Appearance: theme, colors, font and size, layout on the island, display priority, shape. No option was removed and your settings are kept.
